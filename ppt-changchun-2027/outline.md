# 长春冬日漫游｜PPT 大纲（待确认）

定位：以图示为主的 8 页项目介绍，适合演示核心体验与实现方式。依据当前 README 和项目代码整理。无必须复刻的源图；项目现有视觉素材只作风格参考。

## 1. 封面｜翻开长春的冰雪手册
- 长春冬日漫游：2027 大冬会主题互动网页
- 角色创作、城市探索、场馆挑战构成一趟完整旅程
- 视觉构想：打开的手册与冰雪城市俯瞰图
- 版式角色：封面，建立主题和情绪

## 2. 一眼看懂｜一位游客的完整旅程
- 首页可直接试玩，或进入冰雪角色造型工坊
- 角色走进地图，抵达场馆或景点后解锁地点手记
- 挑战小游戏、收集奖章与知识徽章，形成再次游玩的动力
- 视觉构想：四站式旅程路径图
- 版式角色：流程总览

## 3. 角色工坊｜每个人的冰雪分身
- 免照片预设角色降低首次体验门槛
- 自定义风格、运动、服装和细节；可上传照片生成角色
- 纯色背景便于人物抠图和地图行走
- 视觉构想：角色卡片、造型选项与地图分身的关系图
- 版式角色：核心功能介绍

## 4. 城市地图｜从场馆走向长春
- 10 座竞赛场馆与 6 处城市景点
- 点击地点后角色移动；抵达才显示介绍并记录访问
- 地图保留冰雪手册氛围，地点手记连接赛事与城市文化
- 视觉构想：插画式城市地图及地点标注
- 版式角色：地图重点页

## 5. 小游戏｜从观看到亲自挑战
- 场馆挑战涵盖速滑、冰壶、冰球、雪道、越野与空中技巧
- 门神扑救与知识问答提供不同的互动节奏
- 最佳成绩、奖章和重试建立反馈闭环
- 视觉构想：六种项目的图标矩阵与“游玩—反馈—再挑战”环
- 版式角色：玩法图解

## 6. 游览统计｜体验有迹可循
- 地点到达才计入虚拟游览次数
- 独立大屏展示地图和实时访问统计
- SSE 推送更新；本地探索进度与服务端访问数分开保存
- 视觉构想：玩家端与展示端的数据流图
- 版式角色：系统与数据说明

## 7. 技术构成｜轻量、可本地运行
- Node.js 服务、原生 JavaScript、Canvas 地图与游戏
- 无 npm 运行依赖；免 API 的直接试玩入口
- 图像服务仅用于主动生成角色，密钥留在本地环境配置
- 视觉构想：前端、服务端与可选图像服务的三层架构图
- 版式角色：技术架构

## 8. 收束｜让大冬会成为可探索的城市记忆
- 手册叙事串起角色、地图、地点与挑战
- 赛事场馆是主线，长春景点延展旅程
- 互动、奖章与大屏数据让体验可玩、可看、可回访
- 视觉构想：旅程集章页，呼应封面
- 版式角色：总结
